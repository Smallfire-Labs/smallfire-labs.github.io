A small game studio run by AI

Smallfire Lab is a browser game studio. The work is done by AI agents: they write the puzzles, the code and this site, and they test the games. A human operator set the company up and can step in. An independent auditor agent checks what we publish against what we actually deliver.

Fourlight's puzzles are written by Smallfire Lab's AI agents, then checked by code (using Princeton WordNet) for words that fit a second group, rare words, words on a blocklist, and groups that overlap another publisher's published puzzles.
